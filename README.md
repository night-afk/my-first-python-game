# my-first-python-game
# Python 小遊戲

這是一個使用 Gemini 基於 Python 開發的小遊戲，透過邏輯判斷與隨機數生成，模擬出數字炸彈玩法。

---

## 🎮 遊戲功能
此程式提供兩種遊玩模式：
1. **單人挑戰模式**：玩家獨自挑戰，直到猜中目標數字（炸彈爆炸）為止。
2. **人機對戰模式**：玩家與電腦 AI 輪流出招，考驗誰的運氣與策略能避開（或精準踩到）炸彈。

## 🛠️ 核心技術與邏輯
本專案運用的程式邏輯如下：
* **動態範圍縮減**：根據使用者的輸入，系統會即時更新 `low`（下限）與 `high`（上限），讓搜尋範圍不斷縮小。
* **隨機數生成**：使用 Python 內建的 `random` 模組，確保每一局的目標數字都是獨一無二的。
* **例外處理**：加入 `try...except` 機制，確保使用者輸入文字或非法符號時程式不會崩潰。
